PAMANA FLIPBOOK
================
Ready-to-host 22-page static flipbook.

TEST:
Double-click index.html and open it in Chrome/Edge/Firefox.

FREE GITHUB PAGES:
1. Create/login to a free GitHub account.
2. Create a new repository named pamana-flipbook.
3. Upload index.html and the entire pages folder.
4. Repository Settings > Pages.
5. Source: Deploy from a branch.
6. Branch: main / root.
7. Save.
8. GitHub will provide a public address like:
   https://YOURUSERNAME.github.io/pamana-flipbook/

Facebook generally cannot run interactive HTML inside a normal post,
so post the GitHub Pages link. The flipbook opens in the browser.
No subscription, paid flipbook service, or watermark is required.
